# data/

All data for the project is stored here. This includes raw data, sample sheets, and any external data used in analyses. Scientist-provided data, such as cell type classifications (etc) are kept here.

Files or directories in this directory will be symlinked from the working analyses where appropriate.

A symlink to the Genomics STP per-project output is made here as `primary_data/`.

A symlink to BABS' inputs for the project is made here as `inputs/`.
